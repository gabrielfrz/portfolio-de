# Engineered clarity

An editorial portfolio with the precision of an architectural drawing. Typography introduces the person; original line work suggests the practice. The work remains central, while technical details unfold inside reusable case studies.

## Visual system

- Canvas: `#161815`; warm type: `#eeeee7`; secondary type: `#a2a69b`.
- Restrained accent: `#c1ee8d`, used for the surname, selected architecture stage, and closing section.
- Hairline dividers: `#383c33`; technical surfaces: quiet green/graphite neutrals.
- DM Sans for large, tightly spaced editorial headings and body copy; IBM Plex Mono for technical labels; Georgia italic for occasional editorial contrast.
- Maximum content width: 1600px; fluid gutters: 24–88px; paired columns that become deliberate single-column compositions below 760px.

## Choreography

A short load reveal introduces the name and an SVG data sculpture. Project hover raises the line work and responds at the navigation arrow. Small section translations happen once in view. Pipeline packets indicate direction, without playback controls. Selecting a stage changes the explanatory text and announces the update. Native disclosure rows reveal expertise details.

The hero sculpture now has a slow spatial loop and traveling signal traces, without playback controls. No cursor replacement, scroll interception, blocking intro, or artificial loading sequence. Reduced-motion users get the complete static composition.
